This module adds an SMSBOX gateway to ``sms_alternative_provider``: SMS
are sent with the `SMSBOX <https://www.smsbox.net>`__ HTTP API, and
their status is updated from the SMSBOX delivery reports.

Configuration
=============

1. In *Settings > Technical > IAP > IAP Accounts*, create an account
   with the *SMSBOX (HTTP API)* provider, then set:

   - *SMSBOX API Key*: the API key of your SMSBOX client area;
   - *SMSBOX Mode*: *Expert* to send with a registered *SMSBOX Sender*,
     *Standard* to send with a short code;
   - *SMSBOX Strategy*: *Commercial* for marketing SMS, which adds the
     legal STOP mention.

2. In *Settings > Technical > Phone / SMS > SMS Providers*, create a
   provider of type *SMSBOX (HTTP API)* linked to this account, and move
   it first to use it by default.
3. Copy the *SMSBOX Delivery Reports URL* of the account into the SMSBOX
   client area, in *My settings > My preferences > Callback URLs >
   Delivery reports (API)*.
